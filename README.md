# homebrew-optimus

Homebrew tap for [Optimus](https://github.com/brightbraincoder/optimus-releases), an agentic coding CLI by BrightBrainCoder.

```
brew install brightbraincoder/optimus/optimus-cli
```

The installed command is `optimus`. The `Formula/optimus-cli.rb` formula in this repo is generated automatically on every Optimus release — see `scripts/publish-homebrew.mjs` in the main project. A future `optimus-desktop` formula would live alongside it in this same tap.
